Why ScarScript?

Everything you need in a modern language — nothing you don't.

Compiled & Fast

Transpiles to Go, then compiles to a native binary. No interpreter, no VM — just raw performance.

Static Type Checking

Catch bugs at compile time with full type inference, strict rules, and precise file:line:col errors.

Express-Like Syntax

func, val, for..in, string interpolation — feels familiar from day one.

Multiple Returns

Go-style (int, bool) tuples with destructuring: val a, b = divide(10, 2).

Zero Dependencies

Built-in modules: math, file, sys, time. No package manager needed.

Anonymous Functions

Full closures with variable capture. Functional patterns work out of the box.

Quick Start

Up and running in under a minute.

# Install from source
go install github.com/ScarfazeCompany/scar-script/cmd/scar@latest

# hello.scar
func greet(name: str) {
    print("Hello, {name}!")
}

greet("Zawiyar")

# Run it
scar run hello.scar
# Download scar-windows-amd64.exe from Releases
# Rename to scar.exe, then:

scar.exe run hello.scar
scar.exe build hello.scar -o hello.exe
# Download scar-linux-amd64 from Releases
chmod +x scar-linux-amd64
mv scar-linux-amd64 /usr/local/bin/scar

scar run hello.scar
scar build hello.scar -o hello

Language at a Glance

Readable like JavaScript. Safe like Go. Fast as a binary.

// Type inference — just use val / mut / const
val name = "Zawiyar"        // str
mut count = 0              // int
val price = 99.99           // dec

// Functions with multiple returns
func divide(a: int, b: int) (int, bool) {
    if b == 0 { return 0, false }
    return a / b, true
}

val result, ok = divide(10, 2)

// Closures
val double = func(x: int) int { return x * 2 }

// Smart fallbacks
val port = sys.env("PORT") or "8080"

// Built-in modules
val root = math.sqrt(16)     // 4.0
file.write("log.txt", "started")
