Getting Started

Install ScarScript, write your first program, and build a native binary — all in under a minute.

Installation

Choose the method that fits your setup. All methods give you the same scar command.

Option 1: Pre-built Binary (Recommended)

Download the binary for your platform from the Releases page. No Go installation required.

# Download scar-windows-amd64.exe, then rename it:
ren scar-windows-amd64.exe scar.exe

# Verify
scar.exe version
# scar version 1.0.0
# Download and install
wget https://github.com/ScarfazeCompany/scar-script/releases/latest/download/scar-linux-amd64
chmod +x scar-linux-amd64
sudo mv scar-linux-amd64 /usr/local/bin/scar

# Verify
scar version
# scar version 1.0.0
# Apple Silicon (M1/M2/M3)
curl -LO https://github.com/ScarfazeCompany/scar-script/releases/latest/download/scar-darwin-arm64
chmod +x scar-darwin-arm64
sudo mv scar-darwin-arm64 /usr/local/bin/scar

# Intel Mac
curl -LO https://github.com/ScarfazeCompany/scar-script/releases/latest/download/scar-darwin-amd64
chmod +x scar-darwin-amd64
sudo mv scar-darwin-amd64 /usr/local/bin/scar

Option 2: Install with Go

If you already have Go 1.22+ installed:

go install github.com/ScarfazeCompany/scar-script/cmd/scar@latest
Building from source: Clone the repo and run ./scripts/build.sh (Linux/macOS) or .\scripts\build.ps1 (Windows) to produce binaries for all platforms in dist/.

Your First Program

Create a file called hello.scar:

func greet(name: str) {
    print("Hello, {name}!")
}

greet("Zawiyar")

Run it:

$ scar run hello.scar
Hello, Zawiyar!

Build a Binary

Compile your script into a standalone executable:

$ scar build hello.scar -o hello
built hello

$ ./hello
Hello, Zawiyar!
Tip: The output binary has zero dependencies — you can ship it to any machine without installing ScarScript or Go.

Hello World, Complete

A slightly larger example showing variables, functions, and loops:

const APP_NAME: str = "MyApp"

func main() {
    mut count = 0

    for i in 1..5 {
        count = count + i
    }

    print("{APP_NAME} total: {count}")
}

main()
Note: A function marked main is not special — just call your entry function directly at the top level. Every statement in your file runs in order.
