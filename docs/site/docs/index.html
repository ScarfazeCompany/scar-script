What is ScarScript?

ScarScript is a statically-typed, compiled language that transpiles to Go and produces native binaries. It combines Express.js-style syntax with compile-time safety.

func fib(n: int) int {
    if n < 2 { return n }
    return fib(n - 1) + fib(n - 2)
}

for i in 0..10 {
    print("fib({i}) = {fib(i)}")
}
